Integration Instructions

To use Vorld Auth in your app:

  1. Methods already added to Login.js
  2. OTP component ready in App.jsx
  3. EventBus communication setup

To trigger Vorld login:

scene.RequestVorldLogin(email, password)

Or replace existing login button:

btn_login.button.on("pointerdown", () => {
  this.RequestVorldLogin(inputEmailValue.text, inputPasswordValue.text);
});
