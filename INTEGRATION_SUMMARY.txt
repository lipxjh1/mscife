🎯 INTEGRATION FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  User enters email/password
         ↓
  scene.RequestVorldLogin(email, password)
         ↓
  vorldAuth.login() → POST /api/vorld/login
         ↓
  Backend: { success: true, requiresOTP: true }
         ↓
  EventBus.emit('vorld:show-otp', { email })
         ↓
  App.jsx receives event → setShowVorldOTP(true)
         ↓
  OTPInput component renders
         ↓
  User enters 6-digit OTP
         ↓
  vorldAuth.verifyOTP() → POST /api/vorld/verify-otp
         ↓
  Backend: { success: true, user, tokens }
         ↓
  Tokens saved to sessionStorage
         ↓
  EventBus.emit('vorld:otp-success', { user })
         ↓
  Login.js: handleVorldLoginSuccess()
         ↓
  Navigate to Home scene
